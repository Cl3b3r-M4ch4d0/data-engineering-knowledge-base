# Seleção de Tecnologias

Esta seção aborda a avaliação, comparação e seleção de tecnologias para projetos de dados.

A seleção de tecnologias deve considerar os requisitos do projeto, arquitetura, compatibilidade, escalabilidade, desempenho, custos, conhecimento da equipe, complexidade operacional e manutenção a longo prazo.
