# Modelos de Projetos (Project Blueprints)

Esta seção disponibiliza modelos de estruturas de projetos e orientações arquiteturais para diferentes tipos de projetos de dados.

Cada blueprint descreve a estrutura de diretórios recomendada, organização de arquivos, componentes, responsabilidades e boas práticas para construção e manutenção dos projetos.

## Blueprints Disponíveis

- Projetos de Banco de Dados
- Projetos ETL
- Projetos de Data Pipelines
- Projetos de Data Warehouse
- Projetos de Data Lake
- Projetos de Integração de APIs
- Projetos de Migração de Dados
- Projetos de Streaming
- Projetos de Plataformas de Dados End-to-End
