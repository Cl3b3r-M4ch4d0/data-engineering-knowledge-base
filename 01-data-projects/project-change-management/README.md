# Project Change Management

This section covers the identification, evaluation, approval, implementation, and monitoring of changes throughout the lifecycle of data projects.

It establishes processes to manage changes to project scope, requirements, architecture, technologies, schedules, deliverables, and operational procedures while minimizing risks and impacts.

## Main Topics

- Change Management Process
- Change Requests
- Change Identification
- Change Impact Analysis
- Change Evaluation
- Change Approval
- Change Control
- Scope Changes
- Requirements Changes
- Architecture Changes
- Technology Changes
- Schedule Changes
- Change Implementation
- Change Tracking
- Change Logs
- Configuration Management
- Change Communication

# Gerenciamento de Mudanças em Projetos

Esta seção aborda a identificação, avaliação, aprovação, implementação e monitoramento de mudanças ao longo do ciclo de vida de projetos de dados.

Ela estabelece processos para gerenciar alterações de escopo, requisitos, arquitetura, tecnologias, cronogramas, entregáveis e procedimentos operacionais, minimizando riscos e impactos.

- Análise de Impacto

- Aprovação de Mudanças
- Controle de Mudanças
- Alterações de Escopo
- Alterações de Requisitos
- Alterações de Arquitetura
- Alterações de Tecnologias
- Alterações de Cronograma
- Implementação de Mudanças
- Rastreamento de Mudanças
- Registro de Alterações (Change Log)
- Gerenciamento de Configuração
- Comunicação de Mudanças
