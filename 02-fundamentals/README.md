# Data Engineering Fundamentals

## Overview

This section covers the fundamental concepts of data, including data types, formats, structures, lifecycle, processing, storage, and metadata.

The objective is to establish a solid conceptual foundation for understanding how data is represented, organized, managed, processed, and used across Data Engineering environments.

These concepts serve as a foundation for the other sections of this repository, including databases, SQL, data architecture, data integration, data processing, cloud platforms, and data engineering technologies.

| [Data Formats](data-formats/README.md) | Data representation formats, including CSV, JSON, XML, Parquet, Avro, and ORC. |
| [Data Structures](data-structures/README.md) | Data organization structures, including tabular, hierarchical, nested, semi-structured, and unstructured data. |

| [Metadata and Data Dictionary](metadata-and-data-dictionary/README.md) | Metadata, schemas, data dictionaries, catalogs, lineage, and data documentation. |

## Scope

This section focuses on fundamental concepts rather than specific technology implementations.

Technology-specific examples, implementations, comparisons, configurations, and practical use cases will be covered in their respective sections throughout this repository.

# Fundamentos de Engenharia de Dados

## Visão Geral

Esta seção aborda os conceitos fundamentais de dados, incluindo tipos, formatos, estruturas, ciclo de vida, processamento, armazenamento e metadados.

O objetivo é estabelecer uma base conceitual sólida para compreender como os dados são representados, organizados, gerenciados, processados e utilizados nos ambientes de Engenharia de Dados.

Esses conceitos servirão como base para as demais seções deste repositório, incluindo bancos de dados, SQL, arquitetura de dados, integração, processamento, plataformas de cloud e tecnologias de Engenharia de Dados.
